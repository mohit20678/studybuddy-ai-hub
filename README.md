## 🧠 About

**Study Buddy AI Hub** is a free AI study assistant designed for college students.

It combines an AI-powered study chatbot with AI image generation inside a futuristic, animated interface.

Instead of switching between multiple tools for explanations, notes, summaries, quizzes, and visual learning, Study Buddy brings these capabilities together in one simple dashboard.

> 🎯 **Goal:** Make studying with AI simple, visual, interactive, and accessible.

---

## ✨ Features

| Feature | What it does |
|---|---|
| 💬 **AI Study Chat** | Ask questions and get step-by-step explanations |
| 📝 **Smart Notes** | Generate structured study notes from topics |
| 📚 **Summaries** | Turn complex topics into easy-to-understand summaries |
| 🧠 **Quiz Generation** | Generate quizzes to test your understanding |
| 🎨 **AI Image Generator** | Create educational and creative images using AI |
| 🖌️ **Style Picker** | Choose from multiple visual styles |
| 🔐 **Password Login** | Restrict access so only your intended users can use the app |
| 🌌 **Animated UI** | Futuristic black interface with glowing effects and animations |
| ✨ **Interactive Effects** | Floating particles, cursor spotlight, hover effects and pill tabs |
| 🎬 **Video Generation** | Coming soon |
